\# Dudu2idoo Bot 🤖



Bot per puntate automatiche su Bidoo.com



\## Installazione



\### Windows:

1\. Installa \[Node.js](https://nodejs.org/) (versione 18 o superiore)

2\. Esegui `install.bat` come amministratore

3\. Clicca sull'icona sul desktop per avviare



\### macOS:

1\. Installa Node.js: `brew install node` o da \[nodejs.org](https://nodejs.org/)

2\. Esegui nel terminale: `chmod +x install.sh \&\& ./install.sh`

3\. Avvia con: `./run.sh`



\## Utilizzo



1\. Inserisci email e password di Bidoo

2\. Seleziona dominio (it.bidoo.com o es.bidoo.com)

3\. Inserisci ID dell'asta

4\. Imposta i secondi di trigger (es. 3 secondi)

5\. Scegli modalità Manuale o Auto

6\. Clicca GO
